# Personas

## Alpine x-model + x-for select needs :selected and init defaults
Alpine quirk: `x-model` on a `<select>` whose `<option>`s are generated by `x-for` runs before the options exist, so the bound value never selects/updates the DOM option. Always bind `:selected="optionValue === modelValue"` on each `x-for` option. Also, a `<select>` whose first option the browser auto-selects does NOT set the model — initialize defaults in an `x-data init()` (e.g. default `provider`/`model` from `catalog.providers[0]`) and read `$el.value` (not reactive state) inside `@change` handlers to avoid listener-order races.

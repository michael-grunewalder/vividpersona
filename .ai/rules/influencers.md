# Personas

## Alpine x-model + x-for select needs :selected and init defaults
Alpine quirk: `x-model` on a `<select>` whose `<option>`s are generated by `x-for` runs before the options exist, so the bound value never selects/updates the DOM option. Always bind `:selected="optionValue === modelValue"` on each `x-for` option. Also, a `<select>` whose first option the browser auto-selects does NOT set the model — initialize defaults in an `x-data init()` (e.g. default `provider`/`model` from `catalog.providers[0]`) and read `$el.value` (not reactive state) inside `@change` handlers to avoid listener-order races.

## Model selection uses the shared aiModelSelector Alpine component
The persona wizard and the "generate more" form render the family → version → variant cascade via `x-ai-model-selector` (resources/views/components), which registers the global `aiModelSelector(catalog, selected)` Alpine.data in resources/js/app.js. It submits the concrete `ai_model_id` through a hidden input. A level's select is only rendered when that level has more than one option (single options are auto-selected). Preselect the current persona via `:selected="$persona->ai_model_id"`. If you change the selection shape, update BOTH the Blade component and the Alpine.data, and keep the `:selected` + init-default rules above.

## Generation modes live in x-generation-settings
The wizard and the "generate another set" form both use `x-generation-settings` (resources/views/components), which wraps the mode cards (default / custom / three_models) and renders the relevant model selectors. It submits `mode`, plus `ai_model_id` (custom) or `ai_model_ids[]` (three_models) via hidden inputs; the controller ignores inputs for inactive modes (blocks use `x-show`, so hidden inputs stay in the DOM). `GenerationMode` (app/Enums) drives the validation and the plan in `PersonaController::startGeneration`. The show page tags each generated image with its model label (`image.model`) and overlays it as a translucent bottom banner — old sets fall back to `set.model`.
